# Billing components

`commerce.billing.components` maps a **component type** to a factory for a `BillingComponent`: one
priced element of a Plan, such as a per-seat fee or a per-token fee. `BillComposer` reads it. For
each entry in a Plan's component list it builds the component named by `type`, calls
`calculate($period, $config)` and totals the line items into a `ComposedBill`.

## Who fills it

The engine ships **no components**. What you charge for is your vocabulary, not the engine's, so
your application registers every type its Plans name:

```php
use Rushing\Commerce\Billing\ComponentRegistry;

$this->app->make(ComponentRegistry::class)
    ->register('PerSeatFees', fn () => new PerSeatFees($tenant));
```

An entry is the **factory**, not the component. A component is usually built for one billing party
(`$tenant` above), so a closure builds a fresh one per bill instead of sharing an instance. A bare
`BillingComponent` is accepted too, and is wrapped into a factory for you. `make($type)` builds the
component; `resolve($type)` returns the factory.

Because the factory often needs the billing party, you can also build a `ComponentRegistry` of your
own for each bill run and hand it to a `BillComposer`, rather than registering into the shared one.

## Keys

Component types are stored on Plans, usually in PascalCase (`['type' => 'PerSeatFees']`), and they
can't be renamed once persisted. The registry derives a key segment from each one, so
`PerSeatFees` is stored as `per-seat-fees`, and you keep using your own spelling everywhere:
`register('PerSeatFees', …)`, `has('PerSeatFees')` and `make('PerSeatFees')` all find the same entry.
`types()` lists the derived spellings.

## A miss throws

A Plan line naming a type nobody registered is a configuration error, so `make()` throws instead of
falling back to a default. An empty registry is still normal for an application that composes no
bills at all.

## Duplicates

The [**duplicate-key policy**](/beam/docs/foundations/registries#key-policies) is
**supersede**: registering a taken type replaces its factory.
